### Flask Focus App 🚀

A full-stack web application designed to help users improve their productivity by managing and tracking their personal and professional goals. 

### 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Database & ORM:** SQL (SQLite), SQLAlchemy ORM
* **Frontend:** JavaScript (Vanilla), HTML5, CSS3

### ✨ Features

* **Goal Tracking:** Create, update, and delete short-term and long-term productivity goals.
* **Progress Monitoring:** Visualize completion rates and daily focus milestones.
* **Clean Architecture:** Separated frontend and backend logic with an organized database models structure.
